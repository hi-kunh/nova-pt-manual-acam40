# IntelliScan Platinum — ACAM40 보충 매뉴얼

여기에는 **ACAM-40 에서 달라지는 것만** 담았습니다.

## 🚧 상태 — 작성 중입니다

문서 버전 `0.4`. 제목 옆에 `⬜` 가 붙은 자리는 **아직 확인하지 못한 것**입니다.
남은 것은 문서의 **부록 C** 에 모아 두었습니다.

| 표시 | 뜻 |
|---|---|
| ✅ | 실장비로 확인했습니다 |
| 📄 | 프로그램 소스 · 장비 규격 · 제조사 매뉴얼로 확인했습니다 |
| ⬜ | 아직 확인하지 못했습니다 |
